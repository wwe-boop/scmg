# SCMG 论文实验与表格样式（2026-11-05 20:10，配合设计文档 v5）

## 0. 论文范围与 G1 / EX002 叙事
**范围（用户 11-05）**：主线“同信息因果流式不掉质量”；新贡献“音频说话人风格”“与生成器无关的保质量安全层”；语义换检索式机制继续押；打断为分析。

事实：带官方评测器的公开人形机器人伴随语音手势 benchmark 只有 ECHO-G（G1）。我们没有 G1 实机，真机是 EX002（双臂 + 三指手，无腿）。

叙事：
1. **同一方法、两个本体**：SCMG 同一架构、同一配方，分别在 G1 与 EX002 数据上训练；只差输出维度与解码器，EX002 去掉足部项。
2. **G1 = 标准 benchmark**：在 ECHO-G 同数据、同官方评测下比较质量、同一安全滤波后的质量和性能。
3. **EX002 = 真机安全执行**：同一安全层下比较介入量与滤波后质量，并在真机上执行。
4. 局限一节写明：没有 G1 真机；G1 安全为运动学检查加物理仿真。

三座桥：
| 桥 | 做法 | 回答的问题 |
|---|---|---|
| 仿真 – 真机一致性 | EX002 同一批动作做离线违约、MuJoCo 执行仿真、真机执行；只报逐段 Spearman（方法作分层） | G1 只有仿真，结论可信吗 |
| SOTA 上真机 | ECHO-G 的 G1 输出重定向到 EX002（手指保持中立），同一安全层执行；附重定向底噪 | 真机上和 SOTA 比过吗 |
| 两本体方向一致 | A1 / A2 / A8 两本体各做 2 种子 | 结论只对一个本体成立吗 |
