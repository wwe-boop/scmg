# SCMG 论文实验与表格样式（2026-11-05 22:00，配合设计文档 v3）

## 0. G1 评测、EX002 真机：怎么讲圆
事实：公开、带官方评测器的人形机器人伴随语音手势 benchmark 只有 ECHO-G（G1）；我们没有 G1 实机。我们的真机是 EX002（双臂 + 三指手，无腿）。

论文叙事（三句话）：
1. **方法与本体无关**：SCMG 同一架构、同一训练配方，分别在 G1 数据和 EX002 数据上训练；两者只差输出维度（G1 39 维 / EX002 34 维）和解码器。
2. **G1 = 标准 benchmark**：在 ECHO-G 同数据、同官方评测上与 SOTA 公平比较质量、安全（URDF 限位 + MuJoCo 自碰撞 + PD 跟踪执行仿真）、性能。
3. **EX002 = 真机安全执行**：同样的方法和安全模块在真机上执行；并用三座桥证明 G1 上的仿真安全结论可以迁移到真机。

三座桥（每座都是一个可检验的实验）：
| 桥 | 做法 | 回答审稿人的问题 |
|---|---|---|
| B-仿真真机一致性 | EX002 上同一批动作分别做离线契约评测、MuJoCo PD 执行仿真和真机执行，报方法排名和逐段指标的秩相关（Spearman） | “G1 只有仿真，凭什么相信它的安全结论？”——在有真机的本体上证明仿真与离线指标能预测真机 |
| B-SOTA 上真机 | ECHO-G 的 G1 输出经重定向到 EX002，在 EX002 上与我们同一安全层执行；附重定向底噪（G1 真值走同一流程） | “你们真机上没和 SOTA 比”——把 SOTA 搬上我们的真机 |
| B-同一方法两本体 | 两本体用同一组消融（流式训练、自强制、契约损失），看方向是否一致 | “结论是不是只对一个本体成立” |

正文措辞：真机验证只在 EX002 上做；G1 结果为运动学 + 物理仿真。局限一节写明“没有 G1 真机”。
