- **冻结（11-07 12:00）**：生成模型 F 的全部模块与超参在开发集上按 §7 定下，打 tag `paper-final-config`。冻结后只允许新开种子，不改方法。

  - 冻结前待选：G1 契约损失（dlcjgfbijs8er10c）、语义头（dev 车道在跑）、文本编码器（dlci28x6z7uc2dzk）。

## 3. 推理口径（按信息集命名）
| 口径 | 音频 | 文本 | 用途 |
|---|---|---|---|
| P-off | 整句 | 整句 | 与离线方法同条件 |
| P-sync | 前瞻 160 ms | 词念完才可见（与 ECHO-G 滑窗 `--text voiced` 同规则） | **主流式口径，双方信息对等**（C1c） |
| P-TTS | 前瞻 160 ms | x2 到达规则：arrival_j = min(onset_j − 0.15, onset_first − 0.15 + j / 15)；15 词 / 秒，几秒内整句文本可见，未念出的词不带时间 | 机器人部署口径；**含未来文本**；ECHO-G 同用 `--text x2` |
| P-TTS-S | 前瞻 320 ms | 整句文本 + 逐字时间戳 | 部署变体，含未来文本与时间 |
| P-ASR | 前瞻 160 ms | 词念完后再滞后 0.5 s | 人类说话的现实情况 |
| P-audio | 前瞻 160 ms | 无 | 纯音频 |
- ECHO-G 的流式形态有三种：滑窗（不训练）、流式化训练、逐句离线。逐句离线只用于延迟对比（表 3）。
- 前瞻扫描只在开发集做。
- 真 TTS 音频评测：机器人 TTS 合成 val_common 文本，P-TTS 下只报 BA、语义、可执行性、延迟。

## 4. 指标

### 4.1 主表
- 质量（表 1）：FGD↓、ΔDiv↓（另列带符号差）、MM↑、ΔBA↓、\|ΔJerk\|↓（长度加权、逐次取绝对值后平均）、足部↓、滑动↓。
- 可部署性（表 2）：安全（§4.2）、打断（§4.3）、性能（§4.5）。
- MM：每个模型 20 次采样 × 全量 3242 段，按 ECHO-G 协议。

### 4.2 G1 安全
**检查器修正（v3）**
- 碰撞逐帧检查（collision-stride 1，现代码默认 3 帧涂抹，executability.py:26 / :100-103）。
- 排除表（结构性接触连杆对）：用**训练集**真值一次性求出，冻结写进附录；不再按当次评测集动态生成（现代码 :82-88）。
- 先解释真值只有 94.6% 可执行的原因：逐对列出真值违约的连杆对和帧，区分“检查器误报”（网格穿插但物理上允许）与“数据确有违约”。误报加入冻结排除表；确有违约的照实报告。
- 合同内容：位置限位 + 自碰撞 + 速度上限；另加加速度 / jerk 限值（取 G1 电机手册值）作补充列。范围是上半身，基座固定，腿部和平衡不在合同内，正文写明。

**防古德哈特（如实写）**：代理距离阈值是对着 MuJoCo 碰撞标签标定的，与评测同源。处理：
- 标定集改用训练集固定 80 段（清单公开）；
- 另加独立的物理执行评测作为不同源证据。

**物理执行评测**
- 首选：ECHO-G 同款 SONIC 全身跟踪器（11-06 核查能否获得）。
- 退路：MuJoCo 固定基座 + 上身 PD 跟踪，正文明确写“固定基座”。
- 报跟踪误差、自碰撞次数，以及足部与滑动在执行后的变化。

**幅度匹配比较**：可执行率随 Div 变化的曲线；另取 Div 匹配子集（双方 Div 差 < 0.05 的片段）比较可执行率，排除“ECHO-G 动作小所以安全”。

**同一滤波后质量**：所有方法过同一安全滤波，再算 FGD / BA，并报滤波修正 RMSE。

### 4.3 打断与撤回（按代码 scripts/interrupt/eval_interrupt.py 定义）
- 场景：val_common 200 段 × 3 个打断点（句长 30% / 50% / 70%）。评测窗口 2.13 s（64 帧）。
- 指标：
  - yield_rate（窗口内双手回到休息高度并保持的比例，↑）、yield 时间↓；
  - 峰值手部 jerk 与突兀率（超过真人语音后 P95 的比例，↓）；
  - 违约率 unsafe↓；
  - 反应延迟 react↓。
  - rkd（撤回运动学距离：5 个说话人归一化描述量的一维 Wasserstein 距离均值）只作描述，**不作门槛**：它对“不撤回”的续生成更有利（测试集：续生成 0.275、B2 回位 0.99），与“要求回到站立”冲突。
- 基线（按代码）：B1 冻结；B2 临界阻尼回位（按真人中位回位时间；变体 B2fast 1 s、B2mj 最小 jerk、B2q 五次多项式）；B3 流式模型静音续生成；B4 ECHO-G inpainting（待实现，11-08 前做不完就删去并说明）。
- 撤回头的监督不用评测参照分布：训练标签来自训练集真人句末收手段，评测只用 yield / jerk / 突兀 / 违约，不用 rkd，避免循环。

### 4.4 语义时机
- 标签：BEAT2 人工语义标注；**指示 / 象形 / 隐喻**三类为语义；节拍类单独报告，不计入语义结论。
- 主指标 pair_win。对照时刻改为与真实时刻相距 ≥ 2.4 s（识别窗口长度），避免两个窗口重叠压缩动态范围。上下限对照随之重算。
- 识别器 3 个种子，只用训练集真值训练。
- 人工一致性：≥ 300 个事件，标注者看不到方法名与识别器输出（盲评），报 Cohen κ。**标注人力需用户安排**（§11）。

### 4.5 性能（G1 主表三列 + ECHO-G 原定义两列）
- 设备：1 张 RTX 5090 独占；batch 1；预热 1 段不计；val_common 按说话人分层固定抽 100 段。
- 计入范围：从输入到 G1 动作帧的全部组件；两阶段基线含 GMR 重定向，并单列不含重定向的值。
- **峰值内存**：GPU 用 NVML 按进程每 10 ms 采样（含 CUDA 上下文）；主机用 ru_maxrss。另按 ECHO-G 原定义报 **Peak RAM Δ**（请求期间系统内存相对加载前空闲基线的最大增量，MB），与它表 I 的 18542 MB 直接对照。
- **端到端延迟**：语音第 t 帧送入 → 第 t 帧动作可输出，实时推入逐帧测，报均值、p95、首动作延迟。离线方法 = 句末 − t + 整句计算。
- **每帧时间**：计算墙钟 ÷ 输出帧数（30 fps），含特征提取，即 ECHO-G 表 I 的 “E2E Time (ms/frame)” 定义（它报 5.96 ms），两者可直接对照。
- 已测（开发过程）：5090 每个 320 ms 块计算 65.1 ms（流式），折算约 6.8 ms / 帧（未单独测，未含首段特征提取）。
- 实现：scripts/echog_g1/perf_bench.py（新脚本，不改 infer_test.py）；单测：假模型已知 sleep 验证计时误差 < 2 ms，已知大小张量验证显存峰值。

### 4.6 EX002 真机章节：安全执行
问题：生成的手势能不能在真机上安全执行，而且安全层不把手势改坏。
- 安全限值：真机 SafetyGovernor 表（如肩 2 rad/s、12 rad/s²、300 rad/s³）、关节限位、自碰撞、重定向器最后一组安全门；原样写进附录。
- 指标（手臂 + 躯干组、手指组分别报告）：
  1. 原始违约：位置 / 速度 / 加速度 / jerk / 碰撞违约帧率，整段可执行率；
  2. 安全层介入：修改帧比例、修正 RMSE 与最大值（rad）、硬件保护触发次数；
  3. 滤波后质量：EX002 v2 FGD、节拍、语义跟随；FKD 作辅助列（§4.7）；
  4. 安全相关实时性：端到端 p95、帧超时率；
  5. 真机：跟踪误差、急停、碰撞、撤回峰值 / 限值。
- 对照：真值重定向；EMAGE、GestureLSM + 三指重定向（报拒绝率）；**ECHO-G（G1 → EX002 重定向，附重定向底噪）**；BJ50 v0.4.4 发布版；SCMG-EX002（无契约损失 / 契约损失 + 引导；SafetyGovernor 裁剪 / 最小改动投影滤波）。所有方法统一经过同一安全层。
- E7a 离线：2524 段子集 + 开发集 43 段，指标 1–4。
- E7b 真机：
  - SCMG 与 BJ50 发布版各 60 句，其余方法各 30 句；打断 3 点 × 10 次；
  - 比率一律报 Clopper–Pearson 95% 区间，不用“0 次”作安全结论；
  - 影子模式先测到下发为止；发布模式每次上机须用户当场批准。
- 预注册门槛：SCMG 原始违约帧率低于两阶段基线与 BJ50（区间不重叠）；介入 RMSE 低于 BJ50；滤波后 FGD 不劣于 BJ50（边际 +5%）；真机急停率 95% 上界报告，不设门槛。不成立时改写为“同一安全层下的质量与介入量对比”。
- 仿真 – 真机一致性（桥，表 8）：同一批动作的离线违约、MuJoCo 执行仿真、真机跟踪误差三者，按方法和按段报 Spearman。只在相关显著时才写“G1 仿真安全结论可迁移”。
- 现状（开发过程）：手臂 + 躯干违约帧，真值 0.15%，当前 27%（v / a / j 4.7% / 12.4% / 17.5%）；动力学损失只多降 1 个百分点。所以需要外挂安全模块。
