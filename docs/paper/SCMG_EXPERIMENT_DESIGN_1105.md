## 0. 主张与判定规则

**统计**（全部适用，§8）：
- F 用 5 个新训练种子 × 2 个推理种子。
- 与基线比较用配对层次 bootstrap：先重采训练种子，再重采片段（双方用同一组片段），5000 次；FGD 每次重采后重算。
- “优于”= 95% 区间整体在有利一侧。“不劣于”= 区间上界不超过非劣效边际 δ。
- δ 的依据：把真值测试集按说话人分层随机分成两半，两半之间该指标差值的 95 分位（1000 次划分）。在跑任何最终结果之前算出并写进本节。

## 1. 方法与冻结
- SCMG：因果音频编码器 + **因果说话人嵌入**（CAM++，只用已到达的音频前缀，§3）+ 异步双流文本 → 分块规划器（320 ms / 块）→ 局部流（VAE 隐空间，10 步，CFG 2.5）→ 接触感知解码器。
- **冻结时间：11-07 12:00**，打 tag `paper-final-config`。冻结前必须定下的有四项：
  1. 语义头去留：看 D-spk 的 pair_win 提升是否大于开发集双种子差；
  2. 契约损失去留：如果保留，就改用训练集固定 80 段重新标定阈值，并在开发集上用 1 个种子复核；
  3. 文本编码器：e5 或 Qwen3-4B；
  4. 因果说话人嵌入的流式热启动（§3）。
- 冻结后只新开种子，不再改方法。打断改为分析之后，撤回头不再开发。
- EX002 模型 SCMG-EX002 = F 的配方去掉足部项，在 EX002 数据上训 2 个种子，11-09 12:00 单独冻结。EX002 安全模块（推理期契约引导、最小改动投影滤波）同时冻结。

## 3. 推理口径与因果条件
| 口径 | 音频 | 文本 | 说话人嵌入 | 用途 |
|---|---|---|---|---|
| P-off | 整句 | 整句 | 整句 | 与离线方法同条件 |
| **P-sync** | 前瞻 160 ms | x2 到达且词在“当前 + 前瞻”内念完才可见（与 stream_core.visible_tokens 的 voiced 模式逐词一致） | 只用已到达前缀 | **C1c 主口径**，与 ECHO-G 流式化信息对等 |
| P-ASR | 前瞻 160 ms | 词念完后再滞后 0.5 s | 前缀 | 人类说话的现实情况 |
| P-TTS | 前瞻 160 ms | x2 到达，未念出的词可见但不带时间 | 前缀 | 机器人部署口径，含未来文本；ECHO-G 流式化没有按此训练，这一行只报 SCMG |
| P-audio | 前瞻 160 ms | 无 | 前缀 | 纯音频 |

**实现（P0，11-06）**：
- Streamer 加 voiced 与 ASR 两种文本模式；单测与 stream_core.visible_tokens 逐词对拍。
- 因果说话人嵌入：按块用已到达音频前缀重算 CAM++。不足 1 s 时用空嵌入（训练里已有空嵌入的丢弃路径）。
- 训练匹配：流式热启动时，按样本的流式时刻用前缀算嵌入（训练集预先算 1 / 2 / 4 / 8 s 和整段五档）。
- 另报“注册嵌入”变体：用同一说话人其他片段的音频（不用动作）。它属于转导设定，只进补充材料。EX002 部署时 TTS 音色固定，可以用注册嵌入，正文写明。
- ECHO-G + 说话人嵌入用同一套前缀规则。

## 4. 指标

### 4.1 质量
- 官方 7 项：FGD、ΔDiv、MM（20 次 × 全量）、ΔBA、\|ΔJerk\|（长度加权，逐次取绝对值后平均）、足部、滑动。
- **腿部真值 FGD**：把生成结果的 12 个腿部关节和根节点替换成真值后，再用官方 FGD 编码器计算，衡量上身（腰 + 双臂 + 头）的手势质量。所有方法统一这样处理。
- 子集评测（ECHO-G 滑窗 600 段、RoboGesture 300 段）必须在同一子集上给真值、ECHO-G、SCMG 参照行。

### 4.2 G1 安全
- 检查器：
  - 逐帧检查碰撞；
  - 排除表按固定规则从训练集真值一次求出：训练集真值帧中 ≥ 50% 处于接触的连杆对。规则先定，不在看过各方法违约后再改；
  - 新旧两版检查器的结果都报告。
- 合同范围与代码一致：全部 29 个关节的位置 / 速度限位，加全身网格自碰撞，基座固定。加速度 / jerk 作补充列。
- 真值只有 94.6% 可执行：逐对列出真值违约的连杆对和帧数，只作报告，不据此改排除表。
- 幅度匹配：可执行率随 Div 变化的曲线，以及 Div 匹配子集。
- 同一安全滤波：限位裁剪 + 速度 / 加速度限幅。滤波后算官方 FGD 与腿部真值 FGD，并报滤波修正 RMSE。
- 物理执行：SONIC 全身跟踪器（11-06 核查能否获得）；拿不到就用 MuJoCo 固定基座 + PD，正文写明“固定基座”。P1。

### 4.3 打断（分析）
- 按 scripts/interrupt/eval_interrupt.py 的定义：1800 个打断，评测窗口 2.13 s。
- 报告 react、yield_rate、yield 时间、峰值 jerk、突兀率、违约率、rkd（只作描述）。
- 方法：B1、B2、B2fast、B2mj、B2q、B3（静音续生成），分别作用在 ECHO-G、SCMG 离线、SCMG 流式上。

### 4.4 语义时机（C3）
- 三类语义（指示 / 象形 / 隐喻）合并为主指标，节拍类单列。
- pair_win 的对照时刻与真实时刻相距 ≥ 2.4 s，报保留事件数。
- 识别器 3 个种子，只用训练集真值训练。
- 语义头与识别器共用 BEAT2 标签：识别器用训练集真值动作训练，语义头用训练集文本到标签的监督，两者都不接触测试动作。识别器只用于评测与 D-spk 选择，不回传梯度。
