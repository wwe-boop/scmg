# EX002 design D2: causal polyphase equaliser on the vae-r3 decoder output -- pre-registered 2026-11-08 20:4x, before any run
(source: refine-logs/FABLE_DESIGN_1108.md D2 + the main-agent review; owner A; dev only)

Problem. EX002 arm-acceleration window p95 about 2x GT with a 4-frame latent-phase pattern (1.19 / 1.05 / 0.73 / 1.03); the
decoder alone accounts for about 1.2x; the r3d decoder fine-tune traded 7-27 % reconstruction and kept the pattern (negatives 49).

Mechanism. y[t] = sum_{k=0..K} W[phi(t), k, j] * x_hat[t-k, j] + b[phi(t), j], phi(t) = t mod 4 (frame index from the stream start =
the latent grid), K = 7, W diagonal per joint (34 x 4 x 8 weights + 34 x 4 biases), on the decoded motion in radians, causal (frames
before the stream start = the first frame). Fit: ridge least squares toward the identity (penalty lambda ||W - I_k0||^2) on
TRAIN-split VAE round-trips only (mu-encode -> decode of data-v36_1 train items; 2000 items; target = GT frames), lambda picked on a
train-internal hold-out (10 % of the fitting items) from {1e-4, 1e-3, 1e-2, 1e-1, 1}; no dev data enters the fit. Applied directly
after vae.decode, before 5c / keyframes / finger override / safety (scmg/dec_eq.py; switch --dec-eq PATH, default off = bit-identical).
Controls: K = 0 (per-phase affine only); phase-agnostic FIR (same K, W shared across phi); the existing encode-decode re-projection
row for comparison in the full run.

Quick lane (<= 5 min; fit on the CPU from GPU round-trips; 10 dev clips = the first 10 dev recordings ci 0-9):
  - round-trip reconstruction L1 (normalised units, as r3d_gates.py) before / after on the 10 dev clips;
  - per-phase arm-acceleration profile (a = max over arms of ||2nd difference of the 7 arm joints|| x 50^2; mean per phase
    t mod 4, normalised by its mean) on round-trips and on the enc-s0 offline s0 generations of those clips, GT beside it;
  - arm-acceleration 0.2 s window p95 (spikes_where.stat) of the generations, ratio to GT.
  KILL: round-trip L1 worse than r3 on the 10 dev clips, or the round-trip per-phase profile max / min > 1.15 after the fit.
