## Module 3c-2: slack-variable CBF-QP (pre-registered 11-08, before any run)
Per frame the same discrete CBF rows (WBC pairs, d_safe 1 mm, re-linearised at the solution, frames + midpoints), but each collision
row gets a slack s_i >= 0 with cost rho * s_i (rho = 1e4 per metre, L1) -> the QP is always feasible; position and velocity bounds stay
HARD; acceleration / jerk bounds as in cbf_qp (relaxed per joint when they conflict with the hard ones). No hold fallback: if the exact
WBC check still fails after max_iter re-linearisations the frame is the minimum-violation iterate and is counted (residual frames).
Gates (per protocol, selected EX002 base dev outputs offline + psync, per_clip seeds 0-2; the base itself may change after the
liveliness re-selection -- the gates apply to whichever base is selected):
  1. WBC-clear 100 % of frames (residual frames = 0) and position / velocity 100 %
  2. hold / fallback frames 0; frames over the jerk table <= raw + 2 percentage points
  3. dFGD v2 within +-1 raw seed SD; dFKD within +-1 raw seed SD (FKD added because cbf_qp tripled it)
  4. per-chunk p99 <= 100 ms
Addendum (coordinator, before the slack-QP run): also reported for every safety layer -- liveliness change vs its raw input with the
static_share.py definitions (still-frame share, mean wrist speed, wrist amplitude; offline + psync, seeds 0-2), so a layer cannot pass by
damping the motion.
Slack-QP result (11-08, smoke on the first psync s0 recording of the pick, 1760 frames; exp/safe-proj scmg/safety_ex002_3f.py
SlackCBFLayer): FAILS gate 1 before a full run -- 287 WBC-violating output frames (raw 75; residual 317), jerk-over-table frames 47.9 %

## Module 3c-4 (pre-registered 11-08 08:2x, before any run): recursive feasibility of the chunk QP
Cause of the 3c-3c fallbacks: chunk k+1's linearised collision half-spaces (boundary-point planes with the d_safe margin, built from
the NEW raw targets) can exclude every continuation of chunk k's executed frames, although chunk k's verified plan (braking tail to
rest + hold) is itself collision-free, within the position / derivative limits and consistent with the executed history: a
recursive-feasibility gap. Fix (standard MPC shifted-candidate argument): while a verified plan exists, every collision row of
chunk k+1 (initial rows, cutting planes and midpoint rows) is relaxed just enough to admit the shifted plan + hold
(l_row <- min(l_row, a_row . x_shift)); the position, derivative and terminal rows already admit it (same history, same shrink,
the plan ends at rest), so the QP stays feasible whenever a verified plan exists. Safety is unchanged in kind: every output frame is
still certified by the exact WBC test (cutting planes, then the verified plan as fallback). qdldl, tail_smooth 1e-3 and the
memoised linearisation are kept. Run on the new base enc-s0 (ex002-sfscope-1108/enc-s0 bench outputs, offline / psync x seeds 0-2);
gates 1-4 unchanged (gate 2 = 0 fallback frames), reproducibility (second psync s0 run bit-identical), liveliness change reported.
3c-4 first numbers (08:3x, runs/ex002-proj4-enc, enc-s0 outputs): qp_fail 0 in all 6 runs (the infeasibility is gone), but
fallback frames 0 / 16 / 0 (offline s0-s2), 32 / 64 / 0 (psync s0-s2): every remaining fallback is the cutting-plane loop hitting
max_iter 4 (4 solves, the exact WBC test still failing), then the verified plan is executed (a safe brake). Gates 1 / 3 / 4 and
reproducibility pending (check / eval / idle timing running). -> gate 2 FAILS for 3c-4 as registered.
