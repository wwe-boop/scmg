## Module 3c-2: slack-variable CBF-QP (pre-registered 11-08, before any run)
Per frame the same discrete CBF rows (WBC pairs, d_safe 1 mm, re-linearised at the solution, frames + midpoints), but each collision
row gets a slack s_i >= 0 with cost rho * s_i (rho = 1e4 per metre, L1) -> the QP is always feasible; position and velocity bounds stay
HARD; acceleration / jerk bounds as in cbf_qp (relaxed per joint when they conflict with the hard ones). No hold fallback: if the exact
WBC check still fails after max_iter re-linearisations the frame is the minimum-violation iterate and is counted (residual frames).
Gates (per protocol, selected EX002 base dev outputs offline + psync, per_clip seeds 0-2; the base itself may change after the
liveliness re-selection -- the gates apply to whichever base is selected):
  1. WBC-clear 100 % of frames (residual frames = 0) and position / velocity 100 %
  2. hold / fallback frames 0; frames over the jerk table <= raw + 2 percentage points
  3. dFGD v2 within +-1 raw seed SD; dFKD within +-1 raw seed SD (FKD added because cbf_qp tripled it)
  4. per-chunk p99 <= 100 ms
Addendum (coordinator, before the slack-QP run): also reported for every safety layer -- liveliness change vs its raw input with the
static_share.py definitions (still-frame share, mean wrist speed, wrist amplitude; offline + psync, seeds 0-2), so a layer cannot pass by
damping the motion.
Slack-QP result (11-08, smoke on the first psync s0 recording of the pick, 1760 frames; exp/safe-proj scmg/safety_ex002_3f.py
SlackCBFLayer): FAILS gate 1 before a full run -- 287 WBC-violating output frames (raw 75; residual 317), jerk-over-table frames 47.9 %
(raw 8.2 %), per-chunk p99 423 ms. Diagnosis: the per-frame layer only adds barrier rows once a frame already collides (repair on
violation, not a forward-invariant CBF); the hard velocity box and the acc / jerk rows then leave no feasible escape in one frame, so
cbf_qp holds (jerk spikes) and the slack version keeps the violation. A pre-emptive variant (rows of every pair within 3 / 5 cm each frame)
still left 11 / 51 violating frames and 43-46 % jerk frames. The raw violations are 0.4-2 mm intrusions into the 2 mm same-hand
finger-pair margins (left_1_4 / left_3_2 ...). Negatives row on notes/negatives-1107.
